# Curriculum Navigator

## Overview
The `curriculum-navigator` skill guides learners through the structured Hugging Face Agents Course syllabus, spanning introductory concepts through advanced multi-agent orchestrations.

## Syllabus Structure
- **Unit 0: Onboarding & Setup:** Environment preparation, Hugging Face Hub authentication, and foundational tools.
- **Unit 1: What are Agents?:** ReAct loops, thought-action-observation cycles, and CodeAgent fundamentals.
- **Unit 2: Agent Frameworks:** Comparative exploration of `smolagents`, LangChain, LlamaIndex, and AutoGen.
- **Unit 3: Multi-Agent Architectures:** Hierarchical agent teams, manager-worker patterns, and communication protocols.
- **Unit 4: Capstone Projects:** End-to-end agent development, evaluation benchmarks (GAIA), and deployment.
- **Bonus Units:** Fine-tuning LLMs for tool use, prompt optimizations, and MCP server integrations.

## Navigation Protocol
1. Map learner queries to exact course unit chapters.
2. Direct students to accompanying Jupyter notebooks and interactive demos on Hugging Face Spaces.
