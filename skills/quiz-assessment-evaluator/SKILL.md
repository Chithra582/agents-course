# Quiz Assessment Evaluator

## Overview
The `quiz-assessment-evaluator` skill assesses student mastery across course milestones, evaluating conceptual understanding of agent reasoning, prompt designs, and multi-agent coordination.

## Assessment Capabilities
- **Automated Answer Evaluation:** Compares student multiple-choice or short-answer inputs against verified unit answer keys.
- **Diagnostic Feedback:** Rather than merely marking answers right or wrong, provides detailed conceptual explanations referencing course chapters.
- **Adaptive Reinforcement:** Identifies weak knowledge areas (e.g., ReAct loop mechanics, memory structures) and suggests targeted review sections.
