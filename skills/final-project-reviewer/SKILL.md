# Final Project Reviewer

## Overview
The `final-project-reviewer` skill evaluates student capstone projects for graduation and certification in the Hugging Face Agents Course.

## Evaluation Rubric
1. **Agent Architecture (25%):** Appropriate choice of single-agent vs. multi-agent hierarchy for the stated problem.
2. **Tool Integration (25%):** Correct use of custom `@tool` functions, error resilience, and parameter type definitions.
3. **Execution Safety (20%):** Adherence to sandboxing, authorized import whitelisting, and credential hygiene.
4. **Performance & Benchmarking (30%):** Evaluation results against standard benchmarks (GAIA, custom test splits) and solution documentation.
